# micro:bit + Robotbit pH 水質計

版本 0.1.0。適用於所提供的沁和智能類比 pH 模組（VCC、GND、GND、PO、2V5、T1），以及**一支外接供電的 DS18B20**。中文 MakeCode 積木包括校準、量度、讀取水溫和 pH、錯誤診斷。支援目標為 micro:bit V1 / V2；實機驗證狀態見 `VALIDATION.md`。

## 先讀：5V 電源不代表訊號可以直接接

模組 VCC 必須接穩定的 **5V**。用戶手冊明確寫不可用 3.3V。PO 的規格是 **0–5V**；照片中「0–3V」的描述不足以保證所有情況都安全。Robotbit 不會自動把 IO 上的 5V 轉成 micro:bit 可接受的電壓。

電路圖亦顯示 **T1 經 R6（10kΩ）上拉到 VCC，即 5V**。所以 PO、T1 均不能直接接 micro:bit。2V5 是基準電壓輸出，保持不接，不能當電源輸入。接線按實物絲印確認，勿按電路圖的接頭編號或照片上下方向猜測。

### pH 接法（預設 P1）

| 模組／零件 | 接到 |
|---|---|
| 模組 VCC | Robotbit 標示 5V 的輸出 |
| 模組兩個 GND | 共用 GND |
| 模組 PO | 10kΩ 電阻 R上，再到 P1 |
| P1 | 另一顆 10kΩ 電阻 R下，再到 GND |
| 模組 2V5 | 不接 |
| BNC | pH 複合電極 |

```text
模組 PO ── R上 10kΩ ──┬── Robotbit P1（訊號）
                     │
                  R下 10kΩ
                     │
                    GND
```

使用 1% 電阻。分壓後 `VP1 = VPO / 2`，PO 為 5V 時 P1 約 2.5V。校準直接使用分壓後的 ADC 數值，不依賴假設的 ADC 參考電壓。若改變電阻、供電、電位器、探頭或類比腳位，必須重新校準。

先不接 P1，用萬用錶確認供電及分壓接點電壓，再接 micro:bit。模組與 micro:bit 一起供電／斷電，避免模組仍有電時向已關機的 micro:bit 輸入訊號。這個分壓是針對文件所述 0–5V 輸出，不是任意電壓保護器。不要把 PO 接至數碼電平轉換器。

### 水溫接法：以下二選一

**方案 A：保留模組的白色探頭插座。**

插座接 DS18B20，核對 VCC、T、GND 排列。T1 經適合開漏 1-Wire 的 **雙向 5V ↔ 3.3V 電平轉換器**接 P2：

| 電平轉換器端 | 接到 |
|---|---|
| HV | Robotbit 5V |
| LV | 與 micro:bit IO 電源相同的 3.3V 電源 |
| GND | 共用 GND |
| HV 訊號 | pH 模組 T1 |
| LV 訊號 | Robotbit P2 |

兩側須有上拉電阻，按轉換器電路確認；常見 MOSFET 開漏雙向電路可用作此用途，但線長、上拉值和實際波形仍須實測。不能用 PO 的兩電阻分壓方式代替雙向 1-Wire 電平轉換。

**方案 B：DS18B20 獨立接在 3.3V 側，較少電路。**

不把探頭插入 pH 模組；模組 T1 和白色插座留空。DS18B20 VDD 接與 micro:bit 相容的穩定 3.3V，GND 共地，DQ 接 P2，DQ 與 3.3V 之間接 **4.7kΩ 上拉**。DS18B20 外接供電規格至少 3.0V，請確認實際電源符合規格。不要同時接探頭到模組的 5V 插座。

```text
3.3V ───────────── DS18B20 VDD
  │
  └── 4.7kΩ ──┬── DS18B20 DQ
              └── Robotbit P2
GND ───────────── DS18B20 GND
```

只支援三線外接供電、一條總線一支 DS18B20；不支援寄生供電、DS18S20／DS1820 或多探頭定址。線色依探頭廠商為準，資料夾文字只寫紅正黑負，不能據此斷定第三條線和插頭排列。micro:bit 內置溫度讀數是晶片溫度，不能代替水溫。防水探頭才可浸水，電路板及 BNC 保持乾燥。

Robotbit 使用普通 IO **P1、P2**，不要用 S1–S8 舵機接口。P0 預設連蜂鳴器；改用 P0 時先拔蜂鳴器跳線。只使用此 pH 模組時不需要另加 Robotbit 軟件 extension；同一專案可以使用 Robotbit 控制其他配件，但不要佔用 P1／P2，量測時建議停止馬達以減少電源雜訊。

## 安裝 extension

這是一個完整的 MakeCode extension 原始碼套件，**尚未發佈到 GitHub**。ZIP 是原始碼包，不能直接當作 HEX 燒錄，也不是 MakeCode「Extensions」搜尋框可匯入的格式。

1. 建立自己的 GitHub repository，例如 `pxt-ph-meter`。
2. 把本資料夾內的 `pxt.json`、`main.ts`、`onewire.cpp`、`test.ts`、`README.md`、`LICENSE` 等檔案放到 repository 根目錄，不能再包一層資料夾。
3. 在 [MakeCode micro:bit](https://makecode.microbit.org/) 建立專案，選「擴展／Extensions」，貼上該 repository 網址。
4. 出現「pH 水質計」分類後，按下面的流程組合積木。也可切換 JavaScript，貼上 `test.ts` 的示範程式。
5. 本套件含原生 C++ 1-Wire 驅動，初次編譯需要網絡和 MakeCode 編譯服務。只複製 `main.ts` 到普通專案不足以讀水溫。

正式使用前請閱讀 `VALIDATION.md`。模擬器沒有真實探頭，會回報找不到溫度探頭，不會虛構水溫。

另附獨立示範專案 `ph-meter-demo.hex` 時，可先在 MakeCode 首頁選「匯入 → 匯入檔案」載入，或完成安全接線後把 HEX 複製到 MICROBIT 磁碟試機。該示範把驅動放在 `custom.ts`，操作流程放在 `main.ts`；不用 GitHub 即可試用。正式在其他專案重用時，仍建議以上述 GitHub extension 方式安裝。

## 校準及第一次量測

準備新鮮的標準緩衝液、去離子水及萬用錶。優先使校準液和水樣處於同一溫度；例如約 25°C。緩衝液標示 4.00、6.86、9.18 通常對應特定溫度，實際值請按瓶上的溫度表；不要把 6.86 與 7.00 混用。

1. 開機：`設定 pH 類比腳 P1 水溫腳 P2`。此操作清除記憶體中的校準資料並回到預設估算模式；只在開機時呼叫一次。預設不使用溫度補償。
2. 固定電位器位置。若已有正常且不飽和的輸出，可直接做軟件校準。若要按原廠調節硬件，必須在**完成所有調節後**重新量度全部標準液；不能逐點記錄後又改旋鈕，否則前面的校準會失效。
3. 電極放入第一瓶緩衝液，輕輕攪拌，等到讀數穩定；原廠反應時間可達約一分鐘。讀數在約 0.2 秒內穩定，不等於電極已達化學平衡，仍須觀察較長時間。
4. 呼叫 `校準 第一點 緩衝液 pH 6.86 溫度 25`，確認回傳「真」。溫度參數是實際緩衝液溫度，可以先用「量度水溫」取得，確認溫度狀態正常後再填入。
5. 用去離子水沖洗、輕輕吸掉水珠；放入 pH 4.00，待穩定後呼叫 `校準 第二點 緩衝液 pH 4 溫度 25`。
6. 兩點完成即可量度，適合酸性範圍。若要兼顧鹼性，再以 pH 9.18 記錄第三點。三點採用兩段直線插值。
7. 三瓶校準液的溫度最大相差不可超過 1°C。軟件檢查 ADC 點距至少 16、pH 差至少 0.5、pH 越高 ADC 越低；不合格時回傳「假」，保留之前有效資料。請檢查「上次校準操作狀態」。
8. 清洗電極，放入水樣並待穩定，執行 `量度一次（水溫及 pH）`，再讀「上次 pH 值」和「上次水溫 °C」。每次先檢查各自狀態是否「正常」。

`test.ts` 示範：按 A 依次記錄 6.86 → 4.00 → 9.18（三瓶均假設 25°C）；按 B 量一次；按 A+B 清除校準。每次按 A 前必須人工換液並等穩定。若只做兩點，完成第二點後按 B 即可。若使用 7.00 或 10.00 緩衝液，請修改示範內數值。

取下保護帽時保留原有保護液。用後按電極規格放回含保存液的保護帽，勿讓玻璃球泡乾燥。使用過的液體不要倒回標準液瓶。

## 積木及讀數語意

| 積木／API | 行為 |
|---|---|
| `setup(P1, P2)` | 設定腳位並清除校準、舊讀數 |
| `calibrate(point, pH, temperature)` | 量 ADC 並記錄校準點；回傳成功與否 |
| `isCalibrated()` | 是否有有效的 2 或 3 點資料 |
| `measure()` | 更新水溫及 pH，約一秒 |
| `readPH()` | 重新量 pH；開啟補償時也重新量水溫 |
| `readWaterTemperature()` | 重新量水溫，等候 800ms 轉換，再檢查 CRC |
| `readRawADC()` | 校準前也能讀 ADC，令舊 pH 失效；狀態此時表示 ADC 品質 |
| `ph()`、`waterTemperature()` | 只取上次結果，不啟動新量測 |
| `rawADC()`、`adcSpread()` | 中位 ADC（0–1023）、去掉兩個極端樣本後的波幅 |
| `phStatus()`、`temperatureStatus()` | 各自量測狀態；0 為正常 |
| `calibrationStatus()` | 最近一次校準操作的狀態；不等同已完成兩點校準 |

沒有有效 pH、尚未量度或通訊錯誤時，數值回傳 **-1000**，不能當真實讀數。水溫若成功讀取但超出本模組的 0–60°C 應用範圍，仍保留實際讀數，狀態為 `OutOfRange`，禁止拿來做 pH 補償。未校準不會輸出貌似合理的 pH；pH 超出 0–14 亦回報錯誤，不強行截成 0 或 14。

ADC 濾波使用 21 個樣本的中位數。遇到貼近電源上下限、波幅過大會拒絕該次 pH／校準。此判斷無法可靠識別所有斷線或老化的 pH 電極，仍需用已知緩衝液驗證。校準範圍之外使用最近一段直線外推，精度較低；應以標準液涵蓋預期水樣範圍。

| 狀態值 | 意義／處理 |
|---|---|
| 0 | 正常 |
| 1 | 尚未量度，先量一次 |
| 2 | 未完成至少兩點校準 |
| 3 | ADC 接近 0 或 1023，檢查接線、供電、分壓及旋鈕 |
| 4 | 訊號波動大，待穩定並排查雜訊 |
| 5 | 校準資料不合格，檢查標準液、點距、順序和溫度 |
| 6 | 找不到 DS18B20，檢查供電、共地、DQ 和上拉 |
| 7 | 溫度 CRC 校驗失敗，檢查線長、接觸及電平轉換 |
| 8 | 溫度通訊、型號或供電模式不合格 |
| 9 | 超出應用範圍：pH 0–14 或水溫 0–60°C |
| 10 | 腳位錯誤或 pH／水溫用了同一腳 |

顯示兩位小數不代表 ±0.01pH 準確度。以原廠例子的約 0.17V/pH 斜率、二分之一分壓及約 3.3V 的 10-bit ADC 滿量程估算，每個 ADC 數值約相當於 0.04pH；實際還受探頭、電源、ADC、溫度和校準影響。

## 保留校準

### 簡單流程：校準一次，複製一組參數

1. 使用校準示範程式，按 A 記錄第一及第二種標準液；需要三點校準時，再記錄第三種。
2. 完成至少兩點後，程式會透過「輸出 pH 校準參數到 USB 串列」積木，在 MakeCode 的裝置串列主控台輸出一整行以 `PH1,` 開頭的文字。只複製這一行；三點校準請使用第三點完成後最新的一行。
3. 在日常測量程式的「當開機時」，先放設定腳位積木，再把整行文字貼入「載入 pH 校準參數」積木的文字欄。此積木會回傳成功／失敗，請放入「如果」檢查。
4. 重新下載程式。每次開機都會從程式載入同一組參數，毋須每次重新校準。

`measurement-example.ts` 是只測量 pH 的範例：把 `restoreCalibration("")` 的空白文字換成自己的校準參數，再按 B 測量。沒有有效參數時會顯示錯誤，不會輸出假讀數。

使用者只需填入**一個文字欄位**，不用計算斜率。這段文字包含兩點或三點校準所需的多個數值，並非單一修正倍數。它保存在下載到 micro:bit 的程式中，不會寫入感測器。更換控制板、分壓電阻或調整旋鈕後應重新校準。

校準預設保存在 RAM，**重新開機會消失**。完成校準後用串列輸出 `exportCalibration()`，把得到的整段文字放入開機程式，在 `setup()` **之後**呼叫 `restoreCalibration(那段文字)`，檢查回傳是否為真。這是明確、可備份的保存方式，不會偷偷頻繁寫入 flash。

格式為 `PH1,ADC1,pH1,T1,ADC2,pH2,T2`，可再加第三點。格式或資料不合格會拒絕載入，保留原有校準。不要把別一套硬件的資料載入。清除校準後重新開機仍會載入開機程式內的舊文字；要永久更新，必須修改並重新下載程式。

## 溫度補償的範圍

預設關閉，方便在相同溫度下完成校準和量測，也可沒有水溫探頭而只量 pH。

啟用後採用近似 Nernst 斜率修正：

```text
pH補償 = 7 + (pH未補償 - 7) × (T校準 + 273.15) / (T水樣 + 273.15)
```

這假設電極等電位點為 pH 7，電子零點穩定；T校準是有效校準點的平均溫度。這些是模型假設，並非本模組逐支探頭量得的特性。補償只修正電極斜率，不校正水樣自身隨溫度改變的化學性質，也不等於「換算成 25°C 的 pH」。緩衝液自身的 pH 隨溫度變化仍須按瓶上表格手動輸入。

溫度感測失敗時，已開啟補償的 pH 量測會失敗，不會暗中改用 25°C。需要高準確度時，優先把標準液和水樣放在相同溫度，並用獨立儀器驗證。
